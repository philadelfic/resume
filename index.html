Проекты

LLM Second Brain

Self-hosted MCP-сервер «второго мозга» для LLM: даёт моделям (Open WebUI и др.) общий банк заметок с гибридным поиском — векторным и полнотекстовым. Знания живут отдельно от истории чатов, модель получает только релевантное.

  • 🧠 Общий банк знаний для LLM — модели ищут, читают, пишут и обновляют заметки через MCP
  • 🔍 Гибридный поиск — векторный (sqlite-vec) + полнотекстовый (FTS5), слияние через RRF
  • 💰 Экономия токенов — выдача кратких содержаний, а не целых текстов
  • 🛡️ Self-hosted — один Docker-контейнер, non-root, данные не покидают контур
  • 🧩 6 инструментов memory_*: search, list, get, save, update, delete
  • Стек: Python 3.12, FastAPI, SQLite + sqlite-vec + FTS5, Ollama (векторизация/суммаризация), MCP Streamable HTTP, Docker
